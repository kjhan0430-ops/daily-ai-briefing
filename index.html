매일 아침 8시 카카오톡으로 받기

카카오톡 메시지로 오늘자 브리핑을 받는 방법

1. 지금 바로 카톡으로 보내기

오늘 아침 브리핑 요약을 복사하여 카카오톡 '나와의 채팅'에 바로 보낼 수 있습니다.

2. 매일 아침 8시 자동 발송 시스템

프로젝트 폴더에 매일 아침 8시 자동 발송 스크립트가 포함되어 있습니다:

  • send_kakao_briefing.py: 카카오톡 나에게 보내기 발송기
  • setup_kakao.py: 카카오 API 최초 1회 인증 도우미
# 1회 인증 실행
python setup_kakao.py
# 윈도우 작업 스케줄러에 '매일 08:00' 등록 시 끝!
